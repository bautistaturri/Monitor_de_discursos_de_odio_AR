Extracción por usuario

La actividad de Extracción por usuario está implementada en el archivo
actividad1_extraccion_por_usuario.py.

El script lee un archivo usuarios.csv y, para cada usuario, extrae automáticamente los tweets de nivel 1 y 2 dentro de un período definido y en el momento de ejecución.

Como resultado, genera archivos CSV con los tweets recolectados y un archivo de log con las cantidades por usuario y el tiempo de ejecución.
