
## Descripción de la actividad: Extracción por usuario

La actividad de **Extracción por usuario** se encuentra implementada en el archivo
`actividad1_extraccion_por_usuario.py`.

El objetivo principal de esta actividad es preparar la infraestructura necesaria para la recolección sistemática de tweets a partir de un conjunto de usuarios definidos en un archivo externo (`usuarios.csv`).

El script funciona de manera automática, de modo que al modificar el archivo de usuarios, el proceso de extracción se adapta sin necesidad de realizar cambios manuales en el código.
